# Архив комментариев
Обновлено 3 сентября 2026. Папка сервера: E:\CommentAssistantES.
Панель: http://127.0.0.1:8787 → Комментарии.

## Как пользоваться
- «Загрузить все комментарии» начинает проход по всем публикациям, доступным через Instagram API. Дата подключения сервиса и ограничение публикаций для автоответов не отсекают архив.
- Список появляется по мере загрузки. Учитываются все страницы выдачи; в интерфейсе по 50 комментариев на странице.
- «Наш ответ»: все, без нашего ответа, уже ответили, ещё не проверено, комментарии eserv.kz.
- Ответы других пользователей не означают, что компания ответила. Учитывается автор eserv.kz и оба сохранённых ID компании; ручные ответы в Instagram также видны.
- Ответы в ветках показаны под исходным комментарием.
- «Публикация» выбирает один пост. Название берётся из его подписи; в карточке есть ссылка на Instagram.
- «Порядок»: сначала новые, сначала старые, по публикациям.
- «Поиск»: текст или имя автора, без учёта регистра, включая русский язык.
- «Обновить выбранную публикацию» повторно загружает её комментарии и ответы, когда общая загрузка закончена или остановлена.
- «Приостановить загрузку» сохраняет прогресс. «Продолжить загрузку» возобновляет его.
- После полного прохода кнопка меняется на «Обновить все комментарии».

## Чем отличается от автоответов
Архив предназначен для просмотра и не добавляет старые комментарии в очередь отправки.
Режим отправки и дата начала отслеживания не меняются при загрузке.
Обработка новых комментариев и ручная отправка из прежнего интерфейса сохранены в раскрывающемся блоке внизу страницы.
Кнопка на странице «Обзор» теперь загружает архив и открывает «Комментарии». Ранее она проверяла только новые записи после подключения — поэтому список мог оставаться пустым.

## Длительная загрузка
Используется общий локальный предел запросов: по текущим настройкам 160 за скользящий час. Считаются также обращения обычной проверки и неудачные попытки.
При ограничении Meta или локальном пределе загрузка ждёт и автоматически продолжается. Время указано в панели.
Компьютер должен быть включён, пользователь Windows должен войти в систему, интернет должен работать.
Курсоры страниц хранятся в SQLite; сервер продолжает импорт после перезапуска. Закрытие окна браузера не останавливает загрузку.
В предпросмотре обычный опрос временно уступает запросы активной загрузке архива. Работа с очередью отправки при включённых автоответах остаётся отдельной.
Сервис не обходит ограничения Meta. «Все комментарии» означает все записи, которые официальный API разрешает прочитать; удалённые и недоступные записи получить нельзя.
Метка «Без нашего ответа» относится к последней загрузке. Для обновления ручных ответов, сделанных позже в Instagram, обновите публикацию.
Если Instagram не вернул автора ответа или ветка ещё не дочитана, ставится «Ещё не проверено».

## Хранение и проверка
Таблицы library_* находятся в существующем data/history.sqlite. Маркер доступа остаётся защищённым Windows DPAPI.
Удаление данных автора в настройках распространяется на архив и сохраняет отметку от повторного импорта удалённой записи.
Перед внедрением создана резервная копия истории в data/backups.
Проверены: все страницы, ответы компании и других пользователей, неизвестные авторы, продолжение после лимита и перезапуска, пауза во время запроса, фильтры и страницы, удалённые ответы, исключение архива из автоматической отправки.

## Источники API
Официальная коллекция Meta:
https://www.postman.com/meta/instagram/documentation/6yqw8pt/instagram-api
Официальный запрос ответа:
https://www.postman.com/meta/instagram/request/23987686-59e5000b-326c-42a1-8545-b984c7fd0e40
Чтение полей id,text,timestamp,from,parent_id и replies дополнительно проверено реальным GET аккаунта eserv.kz 3 сентября 2026.
Вложенные ответы могут приходить без from, хотя в общей выдаче тот же ID содержит автора. Сервис связывает их по ID; для оставшихся неизвестных авторов отдельно читает объект комментария.

## Написать свой ответ
1. Откройте «Комментарии» и выберите нужную публикацию или фильтр «Без нашего ответа».
2. Под комментарием нажмите «Написать ответ» (для уже отвеченного — «Добавить свой ответ»).
3. Введите свой текст до 2000 символов и нажмите «Отправить в Instagram».
4. Проверьте автора, исходный комментарий и текст в подтверждении публикации.
5. После подтверждённой отправки ответ появится в ветке, а комментарий — в фильтре «Уже ответили».

Ручная отправка работает в предпросмотре и не включает автоматические ответы. На общей паузе отправка выключена. Текст сохраняется при фоновых обновлениях списка и смене фильтра в открытой панели; незавершённый черновик не сохраняется после полной перезагрузки страницы. При отказе сервера/Meta попытка и текст доступны в истории.
Ограничения ответов и минутный интервал общие с автоответами. Загрузка архива оставляет резерв из 10 обращений для действий владельца. После достижения лимита повторите отправку позже.
Повтор одного запроса не публикует дубль. Если Meta не подтвердила POST, повтор блокируется; сначала проверьте Instagram. Сервис никогда не повторяет такой POST автоматически.
