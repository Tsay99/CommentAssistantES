# Comment Assistant ES

Локальный сервер для публичных ответов на комментарии Instagram аккаунта **eserv.kz**.
Компания: ИП Цай. Контакт: Maxtsai99lo@gmail.com.
Папка: E:\CommentAssistantES. Панель: http://127.0.0.1:8787

## Что уже работает

- 100 уникальных редактируемых ответов в 14 категориях, без ИИ и внешних генераторов.
- Смайлики, оттенки кожи, ключевые слова на русском и несколько распространённых приветствий/благодарностей.
- Предпросмотр на собственных примерах без подключения Instagram.
- Чтение новых комментариев через официальный API; только публичные ответы.
- Исключение своих комментариев, чужих упоминаний, рекламных ссылок, неоднозначных и негативных текстов.
- Проверка ручного ответа владельца перед каждым POST.
- История SQLite, сохранение после перезапуска, защита от повторного POST при сетевой неопределённости.
- Маркер зашифрован средствами Windows DPAPI для текущего пользователя, передаётся только Instagram.
- Редактор базы и выгрузка CSV из панели.
- Ручные публичные ответы своим текстом под комментариями архива, в том числе старыми.
- Пауза и локальные пределы отправки и обращений.

## Запуск

Требуется Windows и Node.js 24.15 или новее; внешние npm-пакеты не требуются.

После клонирования репозитория откройте его папку. Рабочая папка может находиться на любом доступном диске; `E:\CommentAssistantES` — исходное размещение сервера. Данные, журналы и секреты создаются локально и не входят в репозиторий. На новом компьютере подключите Instagram через настройки панели.

1. Откройте START.cmd. Либо в PowerShell выполните .\start.ps1 из папки проекта.
2. Откройте OPEN.cmd или адрес http://127.0.0.1:8787.
3. Для остановки откройте STOP.cmd.
4. Не запускайте вторую копию вручную с другим портом против той же базы.

Сервер слушает только 127.0.0.1. Панель доступна на этом компьютере.
E: должно быть доступно; компьютер должен работать и иметь интернет. Сон и выключение прерывают обработку.
Пока сервис читает комментарии через API без Webhook. Обработчик Webhook подготовлен, внешнее подключение отложено. Архив можно загрузить уже сейчас — см. ARCHIVE.md.

## Подключение

1. В панели откройте «Настройки».
2. Вставьте действующий маркер Instagram из Meta в поле «Маркер доступа». Не присылайте его в чат.
3. Если это долгосрочный маркер из панели Meta, отметьте соответствующий пункт: сервис будет обновлять его раз в 7 дней. Краткосрочный маркер не превращается в долгосрочный этой галочкой.
4. Нажмите «Проверить и подключить». Будет проверен аккаунт eserv.kz. Иной аккаунт версия 1 не принимает.
5. Включится предпросмотр. Первый отсчёт начинается с момента подключения.
6. После проверки примеров выберите «Автоответы» и сохраните настройки, подтвердив публикацию.
7. Отсчёт автоответов начинается с момента включения. Исторические комментарии автоматически не отправляются.

Подключение Instagram сохраняется локально. Репозиторий не содержит действующего маркера или истории комментариев.
Если маркер отозван или истёк, сервис ставит обработку на паузу и показывает ошибку. Потребуется снова подключить аккаунт.
Панель не показывает сохранённый маркер обратно.

## Настройки по умолчанию

Предпросмотр, проверка каждые 180 секунд, до 25 публикаций из выдачи Instagram, до 5 публикаций за проход.
Один полный круг по 25 публикациям занимает около 15 минут; это не мгновенные уведомления.
Можно ограничить обработку числовыми ID из загруженного списка публикаций.
Максимум 12 ответов в час и 60 за 24 часа; минимум 60 секунд между отправками.
Локальный потолок 160 запросов в час. При высокой загрузке по заголовкам Meta или её ошибке лимита — пауза на час.
При большом количестве страниц комментариев сервис продолжает обход с сохранённого курсора. Комментарии до момента начала не обрабатываются.

## Как не повторяться

Одна фраза не повторяется под одной публикацией, даже через месяц.
Дополнительно исключаются фразы, использованные где-либо за последние 24 часа, и фразы тому же автору за 30 дней.
Учитываются ID и сохранённый текст фразы, включая перестановку/редактирование банка.
Из допустимых выбирается случайный вариант среди наименее использованных.
Если вариантов нет, комментарий попадает на ручной просмотр. Не очищайте историю ради «сброса» ограничений.
Примеры в панели используют отдельную временную историю и не влияют на реальные ответы.

Цена, наличие, адрес, контакты, а также отдельный 🙏 требуют ручного подтверждения. Сервис не выдумывает цену, адрес или обещание отправить сообщение.
В неизвестных и негативных комментариях не применяется универсальный весёлый ответ.

## Сетевая ошибка при публикации

Если Instagram принял POST, но подтверждение потерялось, повтор мог бы создать дубликат.
Статус «Отправка не подтверждена» НЕ отправляется автоматически заново. Проверьте ветку в Instagram самостоятельно.
После аварийной остановки незавершённые отправки также переходят в этот статус.

## Файлы

- bank.json — рабочая база ответов; безопаснее редактировать через панель.
- RESPONSES-100.csv — первоначальная выгрузка для чтения. Актуальную выгружайте через панель.

- config.example.json — значения по умолчанию.
- data/history.sqlite — настройки, история, очереди.

- test/ — проверки на искусственных данных.

Редактирование config.example.json не меняет уже сохранённые настройки. Используйте панель.
Копирование зашифрованного маркера на другой компьютер или запуск под другим пользователем Windows не даст доступа к нему.

## Запуск после входа в Windows

После первого запуска выполните в PowerShell из папки проекта `./install-autostart.ps1`. Скрипт соберёт фоновое приложение из `background-launcher.cs` и установит задачу CommentAssistantES для текущего пользователя Windows. После входа и затем раз в минуту она проверяет сервер и восстанавливает его после остановки. START.cmd включает работу; STOP.cmd выключает её и ставит отметку, чтобы автозапуск не восстановил намеренно остановленный сервер.
Для отключения: Планировщик заданий → CommentAssistantES → Отключить.
Работа до входа пользователя и полноценная служба Windows в этой версии не настраиваются.

## Обращения об удалении данных

На паузе в настройках можно удалить сохранённые тексты и сведения автора по username.
Остаётся техническая отметка ID комментария от повторной обработки. Сервис не удаляет контент в Instagram.
Сведения об ошибках и счётчики не содержат маркера доступа.
История не очищается автоматически: это сохраняет защиту от дублей. Управляйте сроками хранения согласно вашей политике.

node --test test/*.test.mjs

## Фоновая проверка без всплывающих окон
Задача CommentAssistantES запускает bin/CommentAssistantES.Background.exe. Это приложение Windows без консольного окна; PowerShell запускается с CreateNoWindow и UseShellExecute=false. Исходник: background-launcher.cs, сборка: build-background-launcher.ps1. Проверка сервера остаётся раз в минуту. Последний результат записывается в logs/background-launcher-status.txt без вывода секретов.

## Дополнительный Cloudflare Tunnel

Для периодических проверок и ручных ответов Cloudflare не нужен. Если нужен Webhook, отдельно скачайте официальный `cloudflared.exe` для Windows из [Cloudflare releases](https://github.com/cloudflare/cloudflared/releases) и положите в `bin/`. Исполняемые файлы не входят в репозиторий. Инструкции по Webhook находятся в WEBHOOKS.md.

## Что хранится только локально

`data/`, `logs/`, резервные копии, файлы `.env`, зашифрованные секреты DPAPI и базы SQLite исключены из Git. Сохраняйте резервные копии истории отдельно: она используется для предотвращения повторных ответов. Не размещайте её в GitHub вместе с исходниками.
