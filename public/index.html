Подключить @eserv.kz

Вставьте маркер Instagram из Meta. Он сохранится на E: в зашифрованном виде, доступном вашему пользователю Windows.

Для долгосрочного маркера включится обновление раз в 7 дней. Начальный срок действия пока неизвестен; после обновления Meta сообщит срок.

Режим работы

При включении автоответов отсчёт начинается с текущего момента. Комментарии из предпросмотра не отправляются автоматически.

За проход проверяем до 5 публикаций. При 25 публикациях и интервале 180 секунд полный круг занимает около 15 минут.

Комментарии приходят через Webhooks. Настройки опроса не применяются; ограничение «Только эти ID публикаций» действует.

Пределы и категории

Цена, наличие, адрес и контакты всегда требуют ручного подтверждения. Повтор одной фразы под одной публикацией запрещён, даже когда истекло время. Между отправками — минимум 60 секунд.

Удаление данных по запросу

На паузе можно удалить сохранённые тексты и сведения автора. Техническая отметка ID комментария остаётся, чтобы сервис не ответил повторно.

Требования Meta

Приложение должно быть опубликовано, аккаунт — общедоступным. Документация Meta требует для Webhooks comments расширенный доступ и подтверждение компании. «Готово к тестированию» ещё не подтверждает этот доступ.

Официальная инструкция Meta

1. Секрет приложения

Meta → ваше приложение → «Настройки приложения» → «Основное» → «Секрет приложения» (App Secret). Он нужен для проверки подлинности уведомлений.

2. Публичный адрес

Используем постоянный адрес на вашем домене через Cloudflare. Он сохраняется при перезапуске. Если домена ещё нет, сначала нужно выбрать его; туннель бесплатный, регистрация домена оплачивается отдельно.

Подключение постоянного туннеля Cloudflare

Нужны аккаунт Cloudflare и ваш домен. В Cloudflare: Networking → Tunnels → Create Tunnel. Для маршрута выберите Published application и адрес службы http://127.0.0.1:8788. Публичный адрес должен оканчиваться на /webhooks/instagram.

Это токен конкретного туннеля. Он отличается от секрета Meta и маркера Instagram. Хранится зашифрованным на E:.

3. Подтверждение в Meta

В разделе «Настройте Webhooks» вставьте URL слева в «URL обратного вызова», а строку ниже — в «Подтверждение маркера». Нажмите «Подтвердить и сохранить». Сертификат клиента оставьте выключенным.

Это отдельная строка проверки Webhook. Она не заменяет маркер доступа Instagram.

4. Подписка comments

В Meta включите подписку на поле comments у объекта Instagram. Затем нажмите кнопку ниже: она подключит уведомления для @eserv.kz через API.

5. Перейти на Webhooks

Начните с предпросмотра и оставьте новый комментарий с другого аккаунта. Он должен появиться на странице «Комментарии». После проверки включите автоответы в «Настройках».

Переключение включает предпросмотр. Пауза запрещает обработку и отправку; входящие уведомления в это время отмечаются как пропущенные. Тест Meta с чужим ID подтверждает доставку, но не создаёт комментарий в истории.
